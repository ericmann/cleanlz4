# Spike P1-06: the oracle's end-of-block behaviour

## Question

For each probe below, does `oracle::block::decompress_safe` accept it, with a
capacity equal to the expected decoded length and with that length plus 65,536?
(Block format, "End of block conditions": a decoder "is allowed to reject" a
block that breaks a rule.)

## Method

`cargo run -p oracle --bin probe_eob` builds each probe with
`oracle::craft::build_block` (encoding exactly as Block format, "Compressed
block format" describes) and asks the oracle twice. Probes, with the match
length and literal counts that make each one:

- E0: empty input. E1: the single byte `0x00`.
- R1: a block ending right after a match.
- R2/k: a match of 16 followed by a final run of k literals (k = 5 is the control).
- R3/d: the last match (length 4) begins d bytes before the end of the output, with d - 4 final literals (d = 12 is the control). For d of 5 to 8 the final run is also under 5 bytes, so those probes cannot separate rule 3 from rule 2; d of 9 to 11 isolate rule 3.
- N1/n: a literal-only block whose final token has low nibble n.
- L1/t: one match, t bytes decoded in total (4-byte match, 5 final literals).

## Policy

- Rule 1 (block ends right after a match): **enforce**. R1 is rejected at both capacities.
- Rule 2 (last 5 bytes are literals): **enforce**. R2/0 to R2/4 are rejected at both capacities; R2/5 is accepted.
- Rule 3 (last match starts 12 bytes before the end): **do not enforce**. The probes that isolate it (R3/9 to R3/11, and L1/11 and L1/12) are rejected at exact capacity but accepted with 65,536 bytes of slack, so the oracle's rejection there is a property of the output buffer's size, not of the block. R3/5 to R3/8 are rejected at both capacities, but they also break rule 2. The two capacities disagree on exactly these shapes: a final-literals run of 5 or more with the last match under 12 bytes from the end.
- Empty input (E0): **enforce** as a rejection; the single byte `0x00` (E1) is accepted as the empty block.
- Final token's low nibble (N1): **do not enforce**; every non-zero value is accepted.
